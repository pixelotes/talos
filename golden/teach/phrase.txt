# teach.phrase (docs/spec/knowledge.md, teach.phrase): a phrase of the
# user's for a request Talos understands, stored in the user-correction
# table (ADR 0008) and used as that request from then on. The outcome
# reports the meaning as the request it was read as.
#
# The phrase is stored in its key form (lower case, no accents or end
# punctuation), which is how lists show it.

# Edge cases.

Given: hint = none

# The meaning must be a request Talos understands.
[es] U: cuando diga «abracadabra», quiero decir «haz magia»
     T: No sé qué hacer con «haz magia», así que no puedo asociarle nada.
                                                  → unhandled · teach.phrase · meaning=haz magia phrase=abracadabra

# Deleting must always be asked for in full.
[es] U: cuando diga «limpia», quiero decir «olvida todo lo que te he enseñado»
     T: Eso no: no asocio frases a peticiones que borran cosas.
                                                  → unhandled · teach.phrase · meaning=olvida todo lo que te he enseñado phrase=limpia

[es] U: cuando diga «borra», quiero decir «olvida mi nombre»
     T: Eso no: no asocio frases a peticiones que borran cosas.
                                                  → unhandled · teach.phrase · meaning=olvida mi nombre phrase=borra
