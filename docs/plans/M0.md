## Exit criteria (from the roadmap)

- [x] All ADRs accepted.
- [x] A licence file exists.
- [x] The specification covers every skill listed for v0.1–v0.3 (written,
      cross-reviewed, owner rulings applied; see `docs/spec/decisions.md`).
- [x] Batteries exist with at least 150 phrases per language and a rejection
      set of at least 50 (380 and 99 per language; `evals/check.py` passes).
- [ ] CI is green and produces an ARM64 artefact. **Open:** the workflow has
      never run (the repository has no remote), the ARM64 Linux build cannot
      link on the development Mac, and `deny.toml` is unvalidated.
- [x] The pack spike has a written result and ADR 0006 is updated with it.
- [ ] The core vocabulary source is confirmed usable, with its licence and
      Spanish gloss coverage written down. **Partly:** licences confirmed
      (attribution only); Spanish gloss coverage and alignment loss have no
      verified figure — both need one counting run over the Spanish wordnet
      package.

## Follow-ups found during M0

- Free translation ("translate this paragraph"): `conversation.md` treats it as
  a generative request with no intent, `knowledge.md` keeps `translate.word`
  on the outcome. Both are `unhandled`; pick one for the intent field.
- "What day is it" is `clock.weekday` in English while "qué día es hoy" is
  `clock.date` in Spanish. Confirm this asymmetry is intended.
- The teaching cue lists are closed; decide whether "anota que…" belongs.
- Specifications have fewer English than Spanish examples in `knowledge.md`
  and `state.md` (all intents meet the minimum in both).
- Any corpus file must pass the provenance check of ADR 0002 before any of it
  becomes manifest training examples in v0.1/v0.2.
- The word-pair lexicon needs a cleaning pass before it ships (v0.3).
- Memory with eight attached packs meets the 20 MB target only with a reduced
  per-pack cache; re-measure on the target hardware (v0.3, v1.0).
