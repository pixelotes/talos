# M3 — v0.3 "A dictionary": implementation plan

The working plan for the milestone in [ROADMAP.md](../ROADMAP.md): the store
and its first two uses, defining a word and translating one. Reasoning over
relations and teaching facts are v0.6, on the same schema.

Implementation works from [KNOWLEDGE.md](../KNOWLEDGE.md) (model, schema,
polysemy, packs), [docs/spec/knowledge.md](../spec/knowledge.md) (the fixture
in §1, the shared behaviour in §2, `define`, `translate`, `teach.phrase`) and
the research notes on [pack attachment](../research/pack-attachment.md) and
[the wordnet sources](../research/wordnet-sources.md).

## Slices

```
A  store, packs, seed pack ──▶ B  define, translate, teach.phrase ──▶ D  measure and close
            └────────────────▶ C  vocabulary pack from the wordnets ──┘
```

### Slice A — the store

| # | Task |
|---|---|
| A1 | The SQLite binding: chosen by measured weight (binary size, resident memory), behind a feature if it must be |
| A2 | Schema and migrations as designed in KNOWLEDGE.md §2, relations included |
| A3 | `user.db`: preferences and corrections move out of `user.toml`, read once and migrated |
| A4 | Pack format, attaching packs ([ADR 0006](../adr/0006-knowledge-packs.md)), `talos packs list / check / info` |
| A5 | The seed pack: the fixture of `knowledge.md` §1, hand-written, built by a tool from a text source |
| A6 | Query layer for a dictionary: a word to its concepts (with inflected forms), a concept's gloss per language, a concept's words in the other language, ranked senses |
| A7 | The store reaches a handler through the context; no disk write on a turn that changes nothing |

**Done when** the seed pack is built by one command, attached, and the query
layer answers the fixture's words in tests, with the footprint measured.

### Slice B — the skills (after A)

| # | Task |
|---|---|
| B1 | `define.word`, with sense ranking, context re-ranking and asking which sense |
| B2 | `translate.word`, both directions, and the table of stock phrases |
| B3 | `teach.phrase`: say, list and remove a correction |
| B4 | The cheap fallbacks, each marked in the reply and in the outcome: the English gloss when there is no Spanish one; word by word for a phrase that is not in the table |
| B5 | Manifests, examples, commands (`/define`, `/traduce`), golden files from the specification; retrain |

### Slice C — the vocabulary pack (after A; needs the sources)

| # | Task |
|---|---|
| C1 | Builder: Open English WordNet and the Spanish wordnet joined through CILI; the loss in the join measured |
| C2 | Glosses by source and language; the notices each licence asks for, in the pack |
| C3 | The word-pair lexicon as a pack, after its cleaning pass |
| C4 | Footprint with the pack attached |

The sources are downloaded once at build time and are not committed. The
Spanish wordnet has been fetched; **Open English WordNet and the CILI map
need the owner's permission to download.**

### Slice D — measure and close

A battery for definitions and translations; resident memory and query
latency with a pack of at least 100,000 concepts; the exit criteria of the
roadmap.

## Decisions to take as work starts

| Question | Leaning | Why |
|---|---|---|
| SQLite binding | `rusqlite` with the bundled library | no system dependency on a small board; weight to be measured against a system-library build |
| Full-text search | not in this milestone | a dictionary looks words up by key |
| How a fallback is marked in the outcome | a field beside `status`, decided with B4 | DESIGN.md, principle 8 |
| Inflected forms | rules plus the wordnet exception lists for English; rules for Spanish | wordnet-sources.md §2.4 |
